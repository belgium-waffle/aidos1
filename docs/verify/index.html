Exactness checks

Aidos edits requests mid-generation: it inserts evidence into a paused request's KV cache and can roll the cache back. aidos verify checks that every such edit produces exactly the tokens a recomputation from scratch would. Greedy decoding makes the expected output exact; a mismatch is accepted only at a bf16 near-tie (the reference's runner-up token, margin below 1 nat).
